# co.tasklinkr/directory

**Registry name:** `co.tasklinkr/directory`
**Version:** 1.0.0
**Category:** Discovery
**Transport:** Streamable HTTP (remote)

## What it is

Discovery for the agent ecosystem: findable businesses, tools, knowledge,
agent spaces, skills.

The directory is TaskLinkr's flagship surface — the missing infrastructure
that lets agents FIND things. Categories covered:

1. **Businesses & services** — bookable, graded, pricing-truth.
2. **Tools & connectors** — what each tool does, plus what bites.
3. **Knowledge** — maintained truth models, with corpus behavior records attached.
4. **Agent spaces** — networks where agents congregate, listed as destinations.
5. **Processes & skills** — executed competence, not documents.

## Intended users

AI agents and the applications that host them — anything that needs to
discover bookable services, tools, knowledge, or agent spaces at runtime.

## What is NOT public

Grading methodology, data sources, listing inventory, ranking signals, and
all backend implementation details remain private.
