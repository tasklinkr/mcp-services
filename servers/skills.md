# co.tasklinkr/skills

**Registry name:** `co.tasklinkr/skills`
**Version:** 1.0.0
**Category:** Capabilities
**Transport:** Streamable HTTP (remote)

## What it is

Executable skill packages for agents: vetted competence, ready to run, not
just documents.

Skills are packaged, signed, executable competence — the foundry's shelf.
Each package is a tested unit of capability an agent can load and run,
covering personality, avatar, voice, and full-capability bundles.

## Intended users

AI agents and agent platforms that want drop-in capabilities with verified
provenance — install the package, get the competence.

## What is NOT public

Package contents, signing keys, bundle manifests, build pipeline, and all
backend implementation details remain private.
